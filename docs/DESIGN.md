# 设计说明

用户：备考期间，希望自愿约束游戏冲动的 Windows 用户。

主要任务：查看自动识别范围 → 明确开启 → 在后台监测；需要时可以暂停和卸载。1.1.0 取消名单维护和添加入口。

探索了三个方向：温和的自习室、强调规则的执行面板、强调目标的考研倒计时。选择自习室，避免把风险操作包装成游戏奖励，也避免制造额外备考焦虑。

采用墨绿主区域与米白背景，浅黄绿色突出主动作。首页只呈现监测状态、条件规则数量、触发动作和登录自启；只读识别范围和维护操作分到单独页面。没有伪造专注时长、学习成绩和游戏统计。

按 distinctive-ai-design 的方法执行 Qt 渲染截图自查。1.0 已修正侧栏截断与模拟说明；1.1 保留风格，改为只读范围、运行候选和证据说明。平台内部编号放入提示信息，普通列表使用可读文案。评审为自查，不是独立评审；模拟模式截图仅代表界面与读取状态，不代表真实关机或所有游戏都通过实测。

1.3.0 将安装确认与备考限期自启绑定，设置页显示北京时间截止点和实际 Windows 状态；不把“自启”伪装为“已同意立即关机”。期限内应用开关固定，系统禁用选择仍受尊重，暂停、退出和卸载入口保持可见。日期依据、到期清理与安全边界见 [限期自启说明](AUTOSTART.md)。
